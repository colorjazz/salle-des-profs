# correction

Point de départ du code de correction de Salle des profs : **copie** du module `partage/correction/` de Brûle la pile 1.0 (dépôt `colorjazz/bombe`, commit `55aecf6`, 10 novembre 2026).

| Fichier | Contenu |
|---|---|
| `erreurs.js` | `HttpError` |
| `copies.js` | Prompt de correction (`buildPrompt`), schémas JSON, grilles, calibration, normalisation des notes |
| `langue.js` | Catégories et niveaux de la langue, schémas, prise en compte de la PDA, sous-types d'orthopédagogie (`ORTHO_TYPES`) |

Cette copie évolue librement pour la 2.0 : lien avec les critères et les savoirs, aucune lecture du nom, Montréal seulement. Elle n'est plus synchronisée avec la 1.0. Un correctif utile aux deux versions doit être reporté à la main dans chaque dépôt.
